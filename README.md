
# AirPlay – AI Hand Gesture Game Controller

## Project Overview
AirPlay is a webcam-based hand gesture controller that allows users to control a game without touching the keyboard.

It uses hand tracking to recognize gestures and sends keyboard commands to BlueStacks through a Python bridge.

## Technologies Used
- HTML
- CSS
- JavaScript
- MediaPipe
- Python
- Pynput
- BlueStacks

## Main Features
1. Real-time hand detection.
2. Left and right movement.
3. Jump and attack gestures.
4. Special skill gestures.
5. Two-hand combined gestures.
6. Custom keyboard mapping.
7. Sensitivity adjustment.
8. STOP safety control.

## System Requirements
- Windows 11
- Webcam
- Python
- Google Chrome
- BlueStacks
- Ninja Arashi

## How to Run
1. Start the Python bridge.
2. Open index.html using VS Code Live Server.
3. Allow webcam access.
4. Open Ninja Arashi in BlueStacks.
5. Start controlling the game using hand gestures.

## Project Status
